Fresh — 8 visible steps (B0–7), white dot = now
Stale / old — gauge collapses to an amber dashed arc, dot keeps the value
Past horizon
Gauge = 8 equal arc segments for B0–7 (B8+ is off the gauge on purpose: if the dot ever pins at the end, that is the alarm). Stepped segments make the ramp itself the scale, so the colour, the dot position and the number all agree. In tinted mode the segments become 8 tint steps of increasing opacity; the dot stays full ink.
