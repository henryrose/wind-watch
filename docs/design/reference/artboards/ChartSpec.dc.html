Chart grammar — one drawing, three renderers
Everything below is a bar, a line, a point/rect or system text. Swift Charts: BarMark + LineMark + RuleMark + PointMark + RectangleMark (shading). SVG: rect, polyline, line, circle, text.
Twilight stops as fractions of the hour axis: at t_set opacity 1·day, at t_dusk 0; at t_dawn 0, at t_rise 1·day. Linear in between; hard-held outside. For this payload: 0.2044 → 0.2163, 0.4918 → 0.5037, 0.7370 → 0.7489, 0.9555 → end. Sun dots at t_rise, t_set only.
